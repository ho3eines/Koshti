📦 Android APK

The APK is produced by CI rather than committed to the repo (binaries don't belong in Git, and the build needs the Android SDK).

Download from GitHub Actions

Open the newest green run → Artifacts → koshti-apk. Or build it yourself: 

git clone https://github.com/ho3eines/Koshti
cd Koshti
npm install
npm run android:apk

# → android/app/build/outputs/apk/release/

Requires JDK 21 and Android SDK 36. Tagging a release (git tag v1.0.0 && git push --tags) also attaches the APKs to a GitHub Release.
